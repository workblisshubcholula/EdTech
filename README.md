## Lo que deben entregar

**Antes del sábado 14 a las 12:00** (las presentaciones empiezan a las 12:30), en el **repositorio privado de su equipo**:

### Cómo entrar

1. Inicien sesión en GitHub con el usuario que dieron en su registro.
2. Acepten la invitación: les llegó al correo de su cuenta de GitHub, o ábranla directo en `https://github.com/workblisshubcholula/<su-repositorio>/invitations`.
3. Abran su repositorio. Si ven un error 404, es que no han iniciado sesión o no han aceptado la invitación.

¿No les llegó la invitación o su usuario está mal escrito? Busquen a Daniel González León en el evento.

### Cómo subir sus archivos

Tienen permiso de escritura: pueden subir directo a `main`, sin pull requests.

- **Desde la página:** en su repositorio, **Add file → Upload files**, arrastren sus archivos a la carpeta que corresponde y den clic en **Commit changes**.
- **Desde la terminal:**

```bash
git clone https://github.com/workblisshubcholula/<su-repositorio>.git
cd <su-repositorio>
# ...trabajen...
git add .
git commit -m "Avance del prototipo"
git push
```

¿Su código ya vive en otro repositorio? Pongan el enlace en el `README.md` de su repositorio de equipo y asegúrense de que los organizadores puedan verlo. El deck sí debe estar en `deck/`.

### Reglas

- Nada de contraseñas, llaves de API ni archivos `.env`.
- Nada de datos personales de las personas que probaron su prototipo sin su permiso. Si son menores de edad, necesitan el consentimiento de sus padres o tutores.
- Archivos de más de 50 MB (videos, por ejemplo): súbanlos a Drive o YouTube y dejen el enlace.

| Criterio | Peso |
